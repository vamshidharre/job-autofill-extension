Learned Corrections

Your manual answers and choices are remembered and reused before site defaults, including choices that agree with those defaults. Checkbox choices, including consent, apply only to the same question on the same site. Learning requires Learning mode; file uploads are excluded. Remove an entry to forget that site-specific choice.

This extension runs entirely inside your browser sandbox. Your personal information, work history, credentials, and answers are never transmitted to any external API or cloud server.
